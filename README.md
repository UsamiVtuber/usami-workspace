# Usami

Projeto greenfield de uma companion virtual 3D. A implementação inicial está em preparação.

## Estrutura

- `usami/` — projeto ativo; repo git próprio em `github.com/UsamiVtuber/Usami-Core` (não rastreado aqui)
- `assets/` — fontes de terceiros que alimentam o projeto: `models/` (VRMs, Felis, trabalho original do Autumn, glbs), `sdk/` (Cubism SDK), `images/`, `ideias/`
- `infra/` — infraestrutura local: `n8n-local/` (docker-compose do n8n)
- `vault/` — vault Obsidian local (`Usami Obsidian`)
- `_archive/` — conteúdo único preservado de sessões passadas (`20261024-readmes/`)
- `_backup/` — backups locais, fora do git
