# Usami Frontend

Cliente oficial da Usami.

Este repositório contém a experiência de produto: interface, estado local,
renderização da personagem e comunicação com os serviços oficiais da Usami.
Regras de negócio, memória, RAG e chamadas diretas a provedores de IA não
devem ser implementadas aqui.

## Repositórios relacionados

- `Usami-Backend`: API do produto, identidade, sessões e dados de conta.
- `Usami-AI`: personalização, personalidade, memória, RAG e orquestração de IA.
- `Usami-Contracts`: contratos versionados entre cliente e serviços.

## Status

Repositório inicial. A implementação do cliente será adicionada em commits
seguintes.
